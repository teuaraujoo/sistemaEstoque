# 🤝 Contributing

Obrigado por considerar contribuir com o projeto Sistema de Gerenciamento de Estoque!

---

## Pré-requisitos

- Node.js
- MySQL
- Yarn ou NPM
- Git

---

## Como contribuir

### 1. Fork do projeto

```bash
git fork <repo>
```

### 2. Criar uma branch

```bash
feature/nome-da-feature
fix/nome-do-bug
chore/configuracao
refactor/melhoria
```

---

## Padrões

- Respeitar arquitetura em camadas
- Não misturar responsabilidades
- Manter código limpo e organizado

---

## Commits

```bash
feat: nova funcionalidade
fix: correção de bug
chore: configuração/ajuste geral
refactor: melhoria interna
```

---

## Testes

- Validar CRUD
- Validar regras de negócio
- Garantir integridade do banco

---

## Pull Requests

- Descrever mudanças
- Não quebrar funcionalidades
- Seguir padrão do projeto

---

## Objetivo

Manter o projeto organizado, escalável e próximo de padrões profissionais.

Obrigado por contribuir!
